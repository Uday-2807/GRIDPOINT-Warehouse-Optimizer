# GRIDPOINT — Warehouse Location Optimization

GRIDPOINT is a demand-aware warehouse optimization platform that helps identify efficient warehouse locations by considering **demand, distance, warehouse capacity, and service radius**.

Built using **HTML, JavaScript, Node.js, Express.js, and Weighted K-Means optimization**.

### 🌐 Working Website Link
https://gridpoint-warehouse-optimizer.onrender.com/

### ✨ Features
- Demand-aware warehouse placement
- Multi-warehouse optimization
- Delivery distance & cost analysis
- Capacity and service-radius constraints
- Original vs optimized comparison
- Interactive map visualization
